## 什么情况下值得从 LightNode 换到 Evoxt

### 机器常驻，按月付费

LightNode 的卖点是小时计费和 40 多个地点，这套设计服务的是"开几天就删"的用法。机器一旦变成常年开机，小时计费的优势消失，剩下的就是纯月费对比。同样 4 GB 内存，一年差 $32.52；同样 16 GB，一年差 $56.52。三台机器就是三位数美元。

Evoxt 没有小时计费，这个短板在"常驻"场景里不构成损失。

### 不想自己折腾备份

Evoxt 把每周自动异地备份写成全系标配，零成本，需要时自己恢复。LightNode 的公开套餐页没有列备份，第三方测评站对它的"自动备份"一栏标的是"未核实"。这不是说它一定没有，而是你在下单前无法从公开信息里确认。

对个人站长和小团队，自动备份省下的是另一笔账：要么自己写定时脚本传到对象存储，要么每月另付备份费用。一个月几美元的机器，备份成本占比不低。

### 流量会超，需要知道超了怎么算

Evoxt 的规则写得明确：每台机器给一个免费流量额度，超出后限速，不收超量费。第三方功能库记录，2 核 4 GB 档的免费额度是 2 TB/月。

LightNode 在这件事上是模糊的。它的超量行为取决于具体套餐和地区，官方建议部署前看配置预览。对流量波动大的站点（视频、下载、图片站），规则模糊意味着预算做不准。

月付 $5.99 起的机器还送备份和明确超量规则，这两项加起来，才是它相对便宜的实际含义。想直接对比具体档位，可以按 VM-1 的价格开一台月付实例验证。

## 什么情况下别换

**需要短期测试、按小时跑完就删的。** Evoxt 不支持小时计费，最短按月。第三方功能表把它的 Hourly Billing 一栏明确记为 No。LightNode 官方口径低至 $0.012/小时，按配置和地区浮动。如果你的用法是开几台机器对比线路、跑两天压测、给客户做个临时演示，换到 Evoxt 等于把几天成本变成整月成本。这类需求留在原处更省。

**用户在中国大陆，指望换机房改善晚高峰。** 两家都不解决这个问题。LightNode 的亚洲节点走标准 BGP，没有 CN2 GIA；Evoxt 价格页把香港和日本大阪单列为 Premium Network，但没有公开说明中国大陆方向的优化路由，也找不到可靠的第三方实测数据。想靠换供应商降延迟，方向就错了。真要做，先在香港或大阪开一台月付机器，用你自己的用户群实测一周，再决定要不要动主站。

**需要冷门城市节点。** LightNode 覆盖 40 多个地点，包含中东、非洲、拉美的一批城市；Evoxt 第三方记录是 18 个数据中心、分布在 4 个大洲。需要河内、金边、巴格达、利雅得这类具体落脚点的，Evoxt 给不了。

**磁盘吃紧的。** 前面算过，同内存档 Evoxt 少 10 到 30 GB。现有机器 `df -h` 一看已经用掉 40 GB 的，换过去要么加钱升档，要么先清磁盘，省下的月费可能抵不过升档差价。

**习惯用支付宝付款的。** 第三方功能表记录 Evoxt 的收款方式是信用卡、PayPal 和 Bitcoin，没有列支付宝。这不是说一定不支持，但下单前值得在结账页确认一次，免得卡在付款环节。

## 迁移清单：七步，按顺序做

1. **先量磁盘。** 在旧机器上跑 `df -h` 和 `du -sh /var/log /var/lib/docker`，确认清理后能压到目标套餐的磁盘以内。Evoxt 低档只有 5 到 30 GB，这一步最容易翻车。
2. **确认机房位置。** Evoxt 共 18 个数据中心，香港与日本大阪属 Premium Network。如果用户集中在某个区域，先把实例开在最近的机房，跑一轮真实访问再迁主站。
3. **核对流量额度与超量规则。** Evoxt 是给额度、超了限速、不收超量费，但每档额度不同（VM-2 为 2 TB/月）。对照你上个月的实际上行+下行用量。
4. **确认系统镜像需求。** 官方销售页列出 Windows RDP 与 Linux 两类系统。跑 Windows 应用或需要远程桌面的，先确认目标机房是否提供对应镜像，各地区的镜像可选范围可能不同。
5. **确认支付方式和预付周期。** Evoxt 支持月付到 3 年预付。第一次用，买 1 个月，验证完再考虑长周期，别为了省事一次付三年。
6. **搬数据、切 DNS、观察 48 小时。** Evoxt 控制面板带 VNC、监控图表和 API，出问题时能远程排查。每周自动备份是保底手段，迁移前后各手动拉一次完整备份更稳。
7. **销毁旧实例，不是关机。** LightNode 的官方技术文档明确写着关机的实例仍在计费，不用了必须在控制台释放。迁移完成后忘了这一步，等于两边同时付钱。

## 常见问题

**换供应商要重装系统吗？**

要。跨服务商没有通用的一键搬迁工具，实际流程是旧机器打包网站文件、数据库、证书和配置文件，新机器装好环境再导入。Evoxt 控制面板有克隆功能，但它解决的是同一账户内复制机器，搬不了别家的镜像。

**Evoxt 能按小时计费吗？**

不能，最短按月。第三方功能表把它的小时计费一栏明确记为 No。如果你的机器每月只跑几十小时，LightNode 的按小时模式成本更低，这种情况下没必要换。

**$5.99 的 VM-1 够干什么？**

2 GB 内存、20 GB 磁盘、1 TB 流量、1 核高频 CPU。静态站、WordPress 小站、反代、监控、小型 API 都能跑。不够的是：多个 Docker 镜像同时驻留、图片或视频存储、跑中型数据库。这类需求往上走 VM-2 或 VM-4。

**换过去之后续费会涨吗？**

官网价格页没有标注首期优惠价，表上的 $5.99 就是月付标价，按月续费按这个价格走。长约的实际结算金额以结账页显示为准，下单前看一眼总价。

**能退款吗？**

官方价格页没有写固定退款窗口。Trustpilot 上的评价是混合的：有用户说 2025 年申请退款处理得顺利，也有人反映账户里的剩余余额不退。稳妥做法是先买一个月小额验证，别一次付长周期。同一批评价里还有带宽超量导致 VPS 被暂停、加购带宽两天未生效、支持回复不到位的抱怨，这些都值得在下单前知道。

**性能到底怎么样？**

官方宣称单核主频 3.5 GHz 起、最高 6.0 GHz 以上，这是厂商口径。第三方评测站 VPSBenchmarks 有独立的 Evoxt 页面，记录了功能表和套餐价格，但没有公开的横向跑分结论可以引用。真实表现建议自己开一台月付实例压一轮，成本 $5.99。
